# رجیستری صفحات مرجع (Reference Page Registry)

این صفحات **مرجع تحلیل محصول** هستند، نه وابستگی پیاده‌سازی و نه مجوز کپی کد/محتوا/دارایی.

قواعد الهام‌گیری: [`../architecture/01-product-vision.md`](../architecture/01-product-vision.md)

هرگز کپی نکنید: سورس اختصاصی، محتوای دارای حق نشر، تصویر، لوگو، علامت تجاری، جزئیات پیاده‌سازی اختصاصی.

## وضعیت رجیستری

این رجیستری اولیه است و با Taskهای بعدی می‌تواند گسترش یابد. افزودن مرجع جدید باید هدف تحلیلی روشن داشته باشد و همچنان تحت قواعد عدم‌کپی باقی بماند.
