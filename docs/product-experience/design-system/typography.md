# Design System 2.0 — Typography

| Field | Value |
|-------|--------|
| Parent | [`../DESIGN-SYSTEM-2.0.md`](../DESIGN-SYSTEM-2.0.md) |
| Status | Foundation · `TC-P30-T003` |

## Direction

- Persian-first readability (Iran Sans family direction from North Star, unless a licensed alternative is later locked)
- Strong title → body hierarchy
- Clear price / numeral presentation
- FA / AR / EN first-class
- No page invents a private type scale

## Roles (minimum)

| Role | Use |
|------|-----|
| `display` | Rare hero / marketing moments |
| `title.lg` | Page / section titles |
| `title.md` | Card / panel titles |
| `title.sm` | Dense section headers |
| `body.lg` | Lead paragraphs |
| `body.md` | Default reading text |
| `body.sm` | Dense secondary copy |
| `label` | Form labels / meta |
| `caption` | Hints / timestamps |
| `price` | Monetary amounts / fa-num / en-num clarity |

## Rules

1. Line length stays readable on public content surfaces
2. Admin may use denser type without breaking hierarchy roles
3. Agency mirrors Admin density with clearer action labels
4. Do not mix decorative display fonts into operational surfaces
5. Respect bidi: technical codes / IDs stay LTR islands

## Checkpoint

Exact size/weight matrix may be refined at Visual Checkpoint A before shells.
