# TravelCore.Evolution

Platform capability for **Continuous Evolution foundation boundaries** (Post-P29).

This project declares architecture posture only in early Post-P29 tasks:

- metrics before major evolution
- modular monolith preserved by default
- metrics-driven evolution gate (T003)
- dedicated search engine evolution boundary (T004)
- provider expansion boundary (T005)
- personalization / recommendation evolution boundary (T006)
- loyalty / promotions evolution boundary (T007)
- advanced pricing + mobile + module extraction + deferred scope (T008)
- module ownership preservation

It is **not** a generic evolution toolkit and does **not** introduce microservice extraction, search clusters, ML recommendation engines, loyalty engines, mobile apps, or pricing rewrites until later explicit Post-P29 task envelopes and Accepted ADRs.
